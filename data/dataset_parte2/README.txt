Parte 2 — Road Network (SNAP roadNet-CA)
========================================

Fonte: https://snap.stanford.edu/data/roadNet-CA.html

Coloque o arquivo comprimido aqui:
  roadNet-CA.txt.gz

Download automático (na raiz do projeto):
  python scripts/download_roadnet_ca.py

O arquivo é grande (~dezenas de MB); não é obrigatório versionar no Git.
